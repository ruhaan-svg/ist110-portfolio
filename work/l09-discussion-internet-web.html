L09 The Internet and the Web

Lesson 9, The Internet and Web. Discussion, posted 31 October 2026.

The prompt

Explain the difference between the Internet and the World Wide Web, then cover two more topics. I chose the technologies underneath and the challenges.

My post

The Internet vs. the Web

I used to use these two words for the same thing, but they’re actually different layers. The Internet is the infrastructure: a global network of networks that moves data between devices using TCP/IP. It goes back to ARPANET in 1969. The Web is just one service that runs on top of it. Tim Berners-Lee created it at CERN in 1989 so researchers could share documents through linked pages. The easiest way I’ve found to think about it is that the Internet is the road and the Web is one kind of traffic on it. WhatsApp, email and Spotify all use the Internet without being the Web.

Underlying technologies: what surprised me is how much happens when I type a web address. DNS turns the name into an IP address, TCP/IP breaks my request into packets, a server sends the page back over HTTPS, and my browser displays it. Every link I click starts that process again, and it all happens in under a second.

Challenges: the ITU estimates that about 2.2 billion people were still offline in 2025, mostly in poorer and rural areas. Having moved around a lot growing up, I’ve seen how much access varies from place to place, and as school, banking and job applications move online, that gap shuts people out. Privacy is the other side of it, because the same openness that makes the Web useful also makes it easy to track us.
