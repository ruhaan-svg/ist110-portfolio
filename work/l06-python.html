L06 Python: making the computer decide

Lesson 6, Programming Languages. Assignment, submitted 7 October 2026.

The task

Run, change and test small Python programs in the W3Schools editor, write my own if, elif and else program, then find and fix an error.

What I made

My program decides what to say about a step count:

steps = 6000
if steps > 10000:
    print("Goal smashed!")
elif steps >= 5000:
    print("Almost there.")
else:
    print("Get moving.")

With 6000 steps it printed Almost there. Changing the value to 12000 made the first condition true, so it printed Goal smashed! instead. The error to fix was a missing colon after if battery > 75, which Python reported as SyntaxError: expected ':'. I rated my confidence 3 out of 5 before the activity and 5 after it.

Reflection

Pasting my code added spaces, which caused an IndentationError, and a missing colon stopped the whole program before a single line ran. That was the main lesson: in Python, spacing and punctuation carry meaning, while Excel is much more forgiving about how you type things.

Once that clicked, writing my own if, elif and else program was straightforward, and my confidence went from 3 out of 5 to 5.
