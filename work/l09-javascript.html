L09 JavaScript basics

Lesson 9, The Internet and Web. Assignment, submitted 31 October 2026.

The task

Edit and run W3Schools examples of JavaScript output, events and conditions, then explain how the examples differ.

What I made

Three experiments: an alert that runs as soon as the page loads, a button that shows the date and time when clicked (I relabelled it What time is it, Ruhaan?), and the if, else and else if conditions. The difference I explained is timing. The alert runs straight away, while the button's code sits inside a function that only runs when the onclick event fires.
